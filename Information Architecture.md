# Information Architecture

---
## Sitemap

This sitemap shows the architecture of the website and the relations between each page. The pages are navigated through the use of permanent tabs on the right-hand side of the website.

The sitemap lists each page with their general functions noted below. The rounded boxes represent some of the important features that a particular function will have.

The red lines and boxes are admin exclusive paths, activated by logging in as an admin. This showcases additional features that an admin would have and how the website is structured differently for that user.

The website sitemap starts with a required user login that redirects the user to the correct homepage. Allows the option for the user to navigate to various pages.

## User Flow Diagram

The 4 diagrams show how a user would:
- Post a public request
- Fulfill a public request
- Check their scheduled services (Requested or fulfilled)
- Edit a user’s FUSS Credits as an administrator.

Each diagram finishes with a green diamond; the red lines and boxes require admin privileges to access.
